# 💼 Internship Application Console Program

**BACS2063 — Data Structures and Algorithms**

A Java-based console application developed as part of the **BACS2063 Data Structures and Algorithms** assignment at TAR UMT.

The system provides a simple internship application platform that allows both employers and applicants to access the system through registration and login functionalities.

The project focuses on applying programming concepts and data structures to develop a functional internship application management system.

## 🚀 How to Run

### Prerequisites

Before running the application, make sure you have installed:

- [Apache NetBeans IDE 18](https://netbeans.apache.org/)
- [Java Development Kit (JDK) 20](https://www.oracle.com/java/technologies/javase/jdk20-archive-downloads.html)

### Installation & Execution

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Open **Apache NetBeans IDE 18**.
3. Select **File → Open Project** and locate the downloaded project.
4. Ensure that JDK 20 is configured as the project's Java platform.
5. Navigate to the `Client` folder.
6. Locate and run `TARUMT_Intern.java`.
7. The console application will launch.

## ⚙️ Technical Notes & Limitations

- **Data Storage:** All data is stored in memory during application runtime.
- **Database:** No database connection is implemented.
- **Data Persistence:** Data will be lost when the application terminates.
- **Interface:** Console-based interface designed for straightforward navigation.
- **Project Purpose:** Developed primarily for educational and demonstration purposes.
